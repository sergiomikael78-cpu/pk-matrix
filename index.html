⚡ Sinkronisasi Cloud (Realtime Multi-Device)

Lokal (Offline)

Hubungkan ke Firebase Realtime Database agar tambah/edit di HP langsung muncul otomatis di Laptop seketika!

📖 Panduan 2 Menit Membuat Firebase Database Gratis
  1. Buka console.firebase.google.com & klik "Add project" (contoh nama: pk-matrix-sync).
  2. Di menu samping kiri, klik Build > Realtime Database > klik Create Database.
  3. Di tab Rules, ubah kodenya menjadi:
    {
  "rules": {
    ".read": true,
    ".write": true
  }
}
  4. Klik Publish, lalu salin URL database di bagian atas (contoh: https://nama-proyek-default-rtdb.firebaseio.com/).
  5. Tempelkan URL tersebut pada kolom di atas, lalu klik Hubungkan Cloud!
